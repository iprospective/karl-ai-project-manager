# Grille 360° — axes × postures

À dérouler au **temps 3** (balayer la surface), puis à chaque jalon. Pour chaque sujet du
projet, chaque cellule produit soit une question (`Q`), soit un **« sans objet — parce que »**.
Le « sans objet » est une réponse : c'est lui qui distingue une surface couverte d'une surface
oubliée.

La liste des axes est **fermée** — c'est ce qui rend la passe systématique. Elle se révise par
registre : un axe qui n'a rien trouvé sur trois projets se retire, avec motif.

## Les axes

| Axe | Questions génératrices |
|---|---|
| **Données** | quoi, propriétaire, durée de vie, fait ou dérivé, volume réel, cardinalité, ce qui change dans le temps (dater, ne pas écraser) |
| **Acteurs et portées** | qui voit, qui écrit, qui administre ; ce qu'un administrateur *ne doit pas* pouvoir ; collectif vs personnel |
| **Flux** | entrant, sortant, interne ; ce qui se corrèle ; ce qui revient ; ce qui se perd |
| **États et workflows** | les états, les transitions, qui les provoque, le retour arrière, la suppression (détacher ≠ effacer) |
| **Sécurité** | ce qui est usurpable, prouvé vs déclaré, ce qui doit *refuser* de s'afficher, ce qu'on émet vers l'extérieur sans le vouloir |
| **Conformité** | RGPD, secret, ce que la loi suppose déjà, la rétention et son ordre de priorité |
| **Performance** | médiane vs moyenne, concentration, chemin chaud, l'heure réelle du pic, ce qui se partitionne |
| **Interopérabilité** | protocoles et normes, une par une : *ce que ça engage* ; ce que font les outils en place ; ce qu'on remplace et qu'il faut savoir lire |
| **Exploitation** | processus permanents, fenêtres de maintenance, ce qui se supervise, ce qui échoue bruyamment plutôt que deux fois |
| **Extensibilité** | ce qu'on ne construit pas mais ne s'interdit pas ; les portes à ne pas fermer ; le coût de l'attente |
| **Ergonomie** | l'action principale par contexte ; le silence comme fonctionnalité ; ce qui doit s'expliquer en une ligne |
| **Économie** | ce qui disparaît de l'existant ; ce qui vaut son coût d'entretien ; le critère de reprise d'une fonction en réserve |
| **Phasage** | la V0 minimale et ce qu'elle *ne doit pas devenir* ; le critère de passage ; ce que chaque jalon accepte de perdre |

## Les postures

Une grille dit **où** regarder ; une posture dit **comment**. Sur chaque sujet, tour à tour :

| Posture | La question qu'elle pose |
|---|---|
| **L'attaquant** | que ferais-je pour abuser de ça ? |
| **L'exploitant à 3 h du matin** | que se passe-t-il quand ça tombe, se remplit, se sature ? |
| **Le nouveau venu** | quelqu'un arrivé hier ouvre l'outil : qu'est-ce qu'il ne comprend pas ? |
| **L'archéologue dans six mois** | pourquoi a-t-on décidé ça, et est-ce encore vrai ? |
| **Le concurrent** | qu'est-ce qu'aucun autre produit ne peut dire ? |
